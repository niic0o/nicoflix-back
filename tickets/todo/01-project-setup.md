# TICKET: 01 - Project setup

## Tipo
Chore

## Origen
- Inicialización del proyecto:
- 1. Listar los paquetes npm actualizados a la fecha que no tengan vulnerabilidades y al instalar su versión más reciente, sugiere actualizar solo el ultimo numero (PATCH) ejemplo: "~1.2.4".
- 2. Construye todas las carpetas y template de ejemplos para comenzar a desarrollar.
- 3. Este ticket no tiene funcionalidades para el usuario, solo levanta el proyecto para comenzar a desarrollar generando el correspondiente .env y los script de inicializacion para development y production.
